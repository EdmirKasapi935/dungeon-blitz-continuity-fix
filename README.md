# Dungeon Blitz (classic)

> **Status: Archived**
>
> This project has been archived and moved to private for code protection. Public development has ended, and this repository will not receive further updates, releases, or support. 

## About

**classic-dungeon-blitz** preserves the final public state of the Dungeon Blitz fan revival — **v1.5.22** — so that everyone can keep enjoying the original game experience: running their own servers, exploring the classic regions, and reliving the game exactly as it was. We have moved to private repository to make multiplayer version.

## What you can do

* Clone or fork this repository and run it yourself
* Modify the code freely — the project is fully open source (see [License](#license))
* Host your own dedicated server — see [docs/HOSTING.md](docs/HOSTING.md)

## Version

The final snapshot is **v1.5.22** (tagged). There are no further releases, tags, or branches.
